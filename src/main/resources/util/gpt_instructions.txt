нужно создать html страницы для spring приложения для показа счета футбольных матчей с использованием thymeleaf. первая страница scoreboard.html для пользователей и отображает крупно текущие матчи и ниже более мелко прошедшие матчи, прошедшие матчи должны быть отсортированы по общему количеству голов, выше должны быть матчи с большим суммарным количеством голов за матч. вторая страница должна быть для админа score_board_admin.html, матчи должны отображаться по такому же принципу как у пользователя, но на странице админа должны быть формы для внесения новых матчей, для редактирования текущих матчей, для внесения новых команд с возможностью внесения названия, при добавлении нового матча команды выбираются из выпадающего списка. сущности для матча: Match, переменные private String homeTeam, private String awayTeam;private int homeScore;private int awayScore;private boolean isShowHomeAway; private int startTime;private boolean isMatchOver; Перменная isShowHomeAway ставится в значение true если одна из команд играет на своем поле и это нужно показать в html (подписать сверху над каждой командой "хозяева поля" и "на выезде". Если обе команды играют на чужом поле то значение false и показывать пользователю только названия команд. сущность для команды Team, переменные private String teamName; Есть MatchRepository, в котором должны быть описаны получения списка отсортированного по общему количеству голов(hibernate), Есть MatchService, в котором должна быть описана работа с базой данных postgres, есть контроллер MatchController, в котором должны быть описаны все запросы по получению списка, завершению матча, редактированию, получению и заполнению страниц scoreboard.html и score_board_admin.html.
